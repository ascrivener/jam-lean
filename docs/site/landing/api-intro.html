jam-lean API reference

Every definition and theorem of the jam-lean model, a Lean 4 model of JAM from the Gray Paper v0.8.1. Docstrings cite the paper's section and equation. Start at a library root:

  • JAM: the protocol (Appendix B, §4–§19) built on the PVM;
  • PVM: the Polkadot Virtual Machine (Appendix A);
  • JamCrypto: the model's cryptography parameter, implemented in plain Lean.

The modules under Init, Std, Lean and Lake are Lean's own. See also A Companion to the Gray Paper and the source on GitHub.
