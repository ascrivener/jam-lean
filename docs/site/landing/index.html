jam-lean

A Lean 4 model of JAM from the Gray Paper v0.8.1, used to prove theorems about real compiled service binaries.

Where to start

New to the model? Read the companion's introduction and a chapter, then follow its links into the API reference. In the API reference, start at the library roots: JAM (the protocol, Appendix B and §4–§19), PVM (Appendix A) and JamCrypto (the cryptography, in plain Lean).

Status

  • The companion covers every part of the Gray Paper the model implements (§3–§14, §17, §19 and Appendices A–H), one chapter each. The paper is the authority; the book is a companion to it.
  • The model follows GP v0.8.1 but runs the GP v0.8.0 test vectors (no v0.8.1 vectors are published yet); the accumulate vectors and block import over traces are suspended until they are.
  • Proofs about real service binaries were last checked against the v0.8.0 model.
  • jam-lean is a specification model for proofs: not a node, and not audited.
  • To build and test it, see the README; report errors as GitHub issues.

Contents

  • A Companion to the Gray Paper

    The paper's equations next to the Lean definitions that implement them (read from the model's source), the readings chosen where the paper is ambiguous, and the theorems proved. Each chapter opens with a link to its part of the paper, pinned to v0.8.1.

  • API reference

    Every definition and theorem of the PVM, JAM and JamCrypto libraries, generated by doc-gen4. Docstrings cite the Gray Paper section and equation.

  • Source on GitHub

    The model, what is proved (docs/whats-proven.md) and the model's notes on the paper.
